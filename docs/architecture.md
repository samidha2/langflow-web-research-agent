# System Architecture

## Overview

The Langflow Web Research Agent is an Agentic AI workflow that combines Google Gemini with external web research tools.

The system allows an AI Agent to determine when external information is required and use the available tools before generating a response.

---

## Components

### 1. Chat Input

Receives the user's natural-language query.

### 2. AI Agent

Acts as the central decision-making component.

The agent determines whether external tools are required to answer the user's query.

### 3. Google Gemini

Google Gemini acts as the language model.

It is responsible for:

- Understanding user queries
- Reasoning about the request
- Selecting tools when required
- Processing retrieved information
- Generating the final response

### 4. Web Search

The Web Search tool allows the agent to search the internet for relevant information.

### 5. URL

The URL component retrieves content from webpages.

This allows the agent to work with information available on specific URLs.

### 6. Chat Output

Displays the final response generated by the AI Agent.
